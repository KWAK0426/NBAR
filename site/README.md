# NBAR 홈페이지 배포 파일

시작 화면은 `index.html`입니다. 이 폴더와 하위 `data/`, `assets/`, `reports/`를 같은 상대경로로 유지합니다.

메인 화면은 4개 연구과업을 세로 행으로 표시하고, 현장관측 대시보드는 `field_observation.html`입니다. 관측값과 처리 상태는 `data/nbar-data.js`에서 수정합니다.

전체 인수인계 안내와 Claude Code 작업 문서는 이 폴더 상위의 `README.md`, `CLAUDE.md`, `docs/`에 있습니다.

GitHub Pages의 배포 위치가 저장소 루트라면 이 `site` 폴더 안의 파일과 하위 폴더를 루트에 배치합니다. 실제 Pages 소스 설정은 별도 확인합니다.

화면의 데이터 업데이트 시각은 기존 값을 보존했습니다. 패키지 작성일은 2026-10-19이며, 자료 실적이 그날 갱신되었다는 뜻은 아닙니다.

이번 패키지는 원격 GitHub 저장소를 자동 수정하거나 배포한 결과가 아닙니다.
