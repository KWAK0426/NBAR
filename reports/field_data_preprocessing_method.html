비행 고도·중복도·격자 방향·회차를 정하고, 해당 관측이 패널 기반 처리인지 타프 기반 ELC 처리인지 기록합니다. 센서 종류와 밴드 구성도 회차별로 고정합니다.

확인센서 모델, 밴드 수, 파일 접미사
기록처리 경로, 회차, 기준물 구성

UAV 다분광 영상 취득

입력비행계획과 센서 설정

입력기준물 영상·Ed 시계열·현장 야장
산출회차별 원자료 목록과 시간 기준
1단계

반사도 영상 생성

취득한 원영상은 기준자료에 따라 두 경로로 처리합니다. 패널 관측은 Metashape의 패널 보정 경로를 사용하고, 타프 관측은 외부 Ed와 ELC 계수를 이용해 반사도 TIFF를 먼저 생성합니다.

1-1패널 기반 반사도 생성
  1. DN 다분광 원영상을 Metashape에 입력
  2. 패널 영상과 기준 반사도 지정
  3. Metashape 방사보정 수행
  4. 반사도 상태에서 2단계 처리 진행
1-2타프 기반 ELC 반사도 생성
  1. DN에서 radiance로 방사보정
  2. 센서 간 상호교정 및 RAMSES Ed 시간매칭
  3. 타프 후보영상 선별과 native ROI 지정
  4. Ed 정규화 후 ELC 계수 산출·검증
  5. 전체 영상에 적용하여 반사도 TIFF 생성
1-1.1

패널 기반 반사도 생성

원본 다분광 영상을 그대로 Metashape에 입력하고, 패널 검출과 밴드별 기준 반사도 설정을 통해 반사도 보정을 수행합니다. 구체적인 메뉴 순서와 설정값은 별도 Metashape 처리 지침을 연결합니다.

입력DN 원영상, 패널 영상, 패널 반사도
산출Metashape 내부의 반사도 보정 영상
검증 패널 경로에서는 원영상의 BlackLevel과 센서 메타데이터를 유지합니다.
1-2.1

DN에서 센서 Radiance로 방사보정

각 밴드 DN에서 BlackLevel을 제거하고, 메타데이터의 방사보정계수·비네팅·행 보정·ISO·노출시간을 적용합니다. MicaSense 센서의 공통 방사보정 원리를 따르되 센서 모델별 밴드 구성과 메타데이터를 구분합니다.

입력밴드별 DN TIFF와 XMP/EXIF
산출native 크기의 밴드별 radiance TIFF
MicaSense 방사보정
\[ L_b(r,c)=\frac{a_{1,b}}{2^{n_b}G_b t_{e,b}} V_b(r,c)R_b(r)\max\!\left(DN_b(r,c)-B_b,0\right) \]
\(L_b\)
밴드 \(b\)의 센서 radiance
\(DN_b\)
원영상 디지털 값
\(B_b\)
BlackLevel 평균
\(G_b,t_{e,b}\)
ISO 이득과 노출시간
\(V_b,R_b\)
비네팅과 행 보정계수
\(n_b\)
BitsPerSample
1-2.2

센서 간 상호교정과 RAMSES Ed 시간매칭

센서·밴드별 상호교정계수를 radiance에 적용하고, 각 영상의 촬영시각과 가장 가까운 RAMSES Ed 시각을 대응시킵니다. 위치정보는 관측 이력과 기하 검증에 사용하며 Ed 매칭 기준은 촬영시각입니다.

입력radiance, 센서별 계수, 촬영시각, Ed 시계열
산출상호교정 radiance와 영상별 Ed 연결표
센서 간 상호교정
\[ L_{\mathrm{int},b}(r,c,t)=k^{\mathrm{inter}}_bL_b(r,c,t) \]
가장 가까운 Ed 시각 선택
\[ t_E^{*}(t)=\underset{\tau\in\mathcal T_E}{\operatorname{arg\,min}}\,|t-\tau| \]
1-2.3

타프 후보영상 선별

타프 중심의 EPSG 좌표와 영상 footprint를 이용해 타프가 포함될 가능성이 있는 기준·검증 영상을 추립니다. 후보는 정합 표시영상으로 확인한 뒤, 타프 전체가 안정적으로 보이는 영상만 승인합니다.

입력타프 좌표, 영상 위치·footprint, 촬영번호
산출ELC 기준영상과 독립 검증영상 목록
1-2.4

native 밴드 타프 ROI 설정

타프 중심과 초기 범위를 지정한 뒤, 다중밴드 경계·분할 결과를 이용해 타프 내부 사각영역을 결정합니다. 자동 경계가 불안정하면 네 모서리를 수동 지정하며, ELC 대표값은 정합 표시영상이 아니라 각 밴드의 native 보정영상에서 읽습니다.

입력승인 영상, 타프 중심, 밴드 좌표변환
산출타프·밴드별 native ROI와 유효 화소
ROI 대표 radiance와 변동계수
\[ \bar L_{b,j}=\frac{1}{N_{b,j}}\sum_{i=1}^{N_{b,j}}L_{b,j,i}, \qquad CV_{b,j}(\%)=100\frac{\sigma_{b,j}}{\bar L_{b,j}} \]
검증 경계 혼합화소, 과포화·그림자 화소와 승인된 내부 제외영역을 제거한 뒤 대표값을 계산합니다.
1-2.5

Ed 정규화

각 촬영시각의 조명 차이를 ELC 기준영상 시각 \(t_0\)의 조건으로 맞춥니다. 이 단계는 조명 변화를 보정하며, 관측각 효과는 이후 BRDF 분석에서 처리합니다.

입력상호교정 radiance, 영상별 Ed, 기준시각
산출기준시각 조도로 정규화된 radiance
기준시각 Ed 정규화
\[ q_b(t)=\frac{E_{d,b}(t_0)}{E_{d,b}(t)}, \qquad L_{\mathrm{norm},b}(r,c,t)=q_b(t)L_{\mathrm{int},b}(r,c,t) \]
1-2.6

ELC 계수 산출·검증과 전체 영상 적용

타프 실측 반사도와 정규화 radiance의 관계를 밴드별 선형식으로 적합합니다. 적합에 사용하지 않은 검증영상의 오차를 확인한 뒤, 승인된 계수를 모든 영상에 적용해 반사도 TIFF를 생성합니다.

입력타프 반사도, ROI radiance, 검증영상
산출밴드별 ELC 계수와 reflectance TIFF
ELC 전방모형과 반사도 복원
\[ \bar L_{\mathrm{norm},b,j}=a_b\rho_{b,j}+b_b+\varepsilon_{b,j} \] \[ \widehat\rho_b(r,c,t)= \frac{L_{\mathrm{norm},b}(r,c,t)-\widehat b_b}{\widehat a_b} \]
독립 검증 오차
\[ \operatorname{Bias}=\frac{1}{N}\sum_{i=1}^{N}(\widehat\rho_i-\rho_i), \qquad \operatorname{RMSE}=\sqrt{\frac{1}{N}\sum_{i=1}^{N}(\widehat\rho_i-\rho_i)^2} \]
계수 방향 저장 규칙은 L=a*rho+b로 통일하며 역회귀 계수와 섞지 않습니다.
타프가 없는 관측은 ELC 경로의 대상이 아닙니다. 해당 회차는 패널 기반 처리만 수행하고 ELC 관련 항목은 ‘대상 아님’으로 기록합니다.
2단계

Metashape 처리 및 산출

1단계의 두 처리 경로를 Metashape에서 합칩니다. 카메라 정렬과 지표면 모델을 만든 뒤, 후속 분석에 필요한 영상별 Ortho Photos와 확인용 Ortho Mosaic을 함께 저장합니다.

2.1

입력 영상과 보정 상태 확인

패널 경로는 원영상과 패널 보정 상태를 유지하고, 타프 ELC 경로는 외부에서 생성한 반사도 TIFF를 입력합니다. ELC 반사도 TIFF가 Metashape에서 다시 BlackLevel 보정을 받지 않도록 밴드별 값을 0으로 설정합니다.

패널 경로DN 원영상 + 패널 보정
ELC 경로reflectance TIFF + BlackLevel 0
검증 동일 청크에서 입력 방식과 보정 상태를 혼합하지 않습니다.
2.2

카메라 정렬과 지표면 모델 생성

사진 정렬, 카메라 최적화, 깊이맵 또는 조밀점군 처리, DEM 생성을 수행합니다. 정렬 오차와 위치 오차를 확인하고 필요한 경우 이상 카메라를 정리한 뒤 다시 최적화합니다.

입력반사도 상태의 다중밴드 영상과 카메라 메타데이터
산출정렬 카메라, tie points, DEM
2.3

정사 산출물 내보내기

후속 분석에 필요한 좌표계·해상도·NoData 기준을 고정하고, 영상별 정사영상과 전체 모자이크를 구분해 저장합니다. 영상별 Ortho Photos는 같은 지표화소의 다각도 관측을 보존하므로 BRDF 입력자료 생성에 필수입니다.

입력정렬 청크와 DEM
산출프로젝트, DEM, 카메라 위치, Ortho Photos, Mosaic
Metashape 프로젝트정렬·보정 상태와 처리 이력을 보존
DEM정사투영과 관측기하 계산의 지표고도 기준
GPS_est.txt최적화된 카메라 위치와 촬영영상 연결정보
Ortho Photos영상별 관측각과 반사도를 유지한 정사영상
Ortho Mosaic회차 전체의 공간 분포 확인과 보고용 영상
처리 기록좌표계·해상도·NoData·보정 경로와 설정값
영상 전처리는 이 단계의 정사 산출물 생성에서 끝납니다. 연구 대상지 마스킹, 반사도·관측기하 적층, BRDF inversion 및 NBAR 영상 생성은 ‘결과 생성·분석 방법서’의 범위입니다.
