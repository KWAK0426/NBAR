HTML 보고서 간편 편집기

보고서 HTML을 선택하면 자동으로 편집 모드가 켜집니다. 글과 표의 기본 스타일만 수정하고, 원본은 덮어쓰지 않습니다.

1HTML 파일 선택

수정할 보고서 HTML을 선택하세요. 선택하면 바로 글을 수정할 수 있는 상태가 됩니다.

이미지가 안 보일 때만 열기

보고서의 이미지가 HTML 안에 포함되어 있으면 필요 없습니다. 이미지가 별도 assets 폴더에 있을 때만 그 폴더를 선택하세요.

2편집

제목, 본문, 표 안의 글자를 클릭해서 수정합니다. 표 칸을 클릭하면 스타일 팝업이 열립니다.

3찾기 / 바꾸기

공백 정리는 여러 칸 공백과 문장부호 주변의 불필요한 공백을 정리합니다.

4수정본 저장

수정본은 새 HTML 파일로 저장됩니다. 원본 파일은 그대로 남습니다.

표 스타일 수정 표 칸을 클릭하면 오른쪽 팝업에서 가운데 정렬, 왼쪽/오른쪽 정렬, 글자 크기, 굵게, 배경 강조를 바꿀 수 있습니다.
HTML 파일을 선택하세요.
