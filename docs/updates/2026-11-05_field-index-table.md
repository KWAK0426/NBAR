# 현장관측 인덱스 표 형식 전환 (2026-11-05)

- 피복 탭을 없애고 전체 관측을 한 표로 표시한다. 피복 필터를 두고, 탭의 "밭 1회" 같은 횟수 표시는 뺐다. 사용자 요청: 농지 외 피복의 횟수가 적어 탭으로 내놓기 어색함.
- 기관 필터와 대상지 아래 기관명은 `agency` 값이 둘 이상일 때만 나타난다. 농과원 위성센터 관측은 목록을 받으면 추가한다. 현재 실제 데이터에는 없다.
- 표 열: 날짜 · 대상 · 대상지 · 생육시기 · 당일 반복관측 횟수 · 보고서. 생육시기 색 배지를 뺐다. 목록 폭이 760px 이하이면 여러 줄로 바뀐다.
- 보고서 칸: 처음에 보기·초안·미작성 글자로 바꿨으나 사용자 요청으로 버튼을 복구했다. 완성본은 파란 버튼, 완성 전은 회색빛 버튼이고 준비중 같은 글자는 없다. 회색빛 버튼도 파일이 있으면 열린다. `reportDraft`는 삭제했다.
- 사용자 요청으로 목록 글씨와 줄 간격을 키웠다(본문 14→18px). 이후 페이지 전체 글씨를 1.3배로 키우고 표 전체를 가운데 정렬했다(본문 23px). 사용자 요청으로 모든 글씨를 2px씩 줄였다(본문 21px).
- 전체 합계 칸과 월별 구분을 넣어 배포했다가(3f12401) 사용자 요청으로 뺐다. "전체 관측 N회" 표시도 사용자 요청으로 뺐다. 횟수가 적어 보이는 것을 피하려는 것이므로 인덱스에 횟수 합계를 넣지 않는다.
- 화면 문구: "처리 완료 회차"→"데이터 처리 완료 회차", "영상 수"→"수집한 다분광 영상 수".
- 확인: check_data 문제 0. 로컬 1440px, 375px 화면과 필터·정렬·선택. 기관 표시는 임시 예시 관측으로 확인 후 삭제. PC에서 13개 관측이 스크롤 없이 표시됨.
- B에는 A의 페이지와 데이터를 복사했다. B는 noindex를 유지하고 6/30 링크는 B 안의 보고서를 쓴다. 제목 "선택 관측 상세"는 A와 다르게 남아 있다.
