# 날짜별 보고서 폴더의 관측 기관 구분 (2026-11-13)

- 작업자: Codex.
- 현황판 관측 기관을 기준으로 드라이브의 8개 대상지 폴더를 부산대학교 5개 / 위성센터 3개로 구분하고 각 기관 안에서 번호를 다시 매겼다. 기존 폴더 ID와 날짜별 내용은 유지했다.
- 농업위성센터 나지 6월 10일은 대상지 명칭과 구별해 현황판의 부산대학교 관측으로 분류했다.
- GitHub의 보고서 업로드 안내와 공동 작업 기록을 갱신했다. 사이트 코드 및 자료 상태 변경 없음.
- 검증: 두 드라이브 기관 폴더의 대상지 목록 확인. 기존 링크 검사에 사이트 밖 상대경로 4건이 남아 있다.
